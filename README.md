# Weather Dashboard

A static weather dashboard with city search, geolocation, temperature-unit switching, current conditions, and a five-day forecast.

## Run

Open `weather-1 (1).html` in a browser or serve the repository with any static web server.

## Security

The application does not contain a committed weather API key. Weather data is fetched from Open-Meteo, which does not require an API key for this client-side demo.
